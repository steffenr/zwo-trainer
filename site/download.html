Getting started

From download to first ride.

  1. Install and open

    Allow the unsigned app once and grant Bluetooth access.

  2. Choose your folder

    Select the folder that contains your .zwo workouts and plans.

  3. Set up your rider

    Enter name, FTP and weight, or ride an FTP test first.

  4. Pair and ride

    Connect trainer, heart-rate strap and controller from the Bluetooth menu, then start a workout.

FAQ

Common questions.

Is zwoTrainer free?

Yes. There is no subscription, no account and no ads. The source code is on GitHub.

Where do I get workouts?

Any Zwift .zwo file works: exported from Zwift, downloaded from a workout site or written by a coach. To use workouts as a plan, put them in a folder and sort them by week and day.

Why does my system warn me when I open it?

The installers aren't signed with a paid developer certificate. On macOS, right-click the app and choose Open, or use System Settings → Privacy & Security → Open Anyway. On Windows, choose More info → Run anyway.

Which trainers work?

Any Bluetooth smart trainer with FTMS, for example Wahoo KICKR and KICKR Core, Zwift Hub, Tacx, Elite, Saris and JetBlack. Bluetooth power meters and heart-rate straps work too.

Can I run it at the same time as Zwift?

No. Most trainers and controllers accept only one Bluetooth connection, so close Zwift and other training apps first.

Do my rides reach Strava?

Yes, through Garmin Connect. Link Strava to your Garmin account once, and every uploaded ride is forwarded under the workout's name. The ride description doesn't reach Strava.

Does my Garmin password go through the app?

No. You sign in on Garmin's own page, and zwoTrainer stores only the resulting session token, per rider, on your computer.
